## 🌟 Tính năng nổi bật:
- 📱 **Mobile & Desktop 100% Responsive**: Giao diện tối ưu hoàn hảo cho điện thoại di động (Menu Drawer, Fullscreen AI Chat).
- 🛠 **Live C# Code Runner & Terminal Console**: Tự gõ code và chạy thử trực tiếp trên trình duyệt, in output `Console.WriteLine` thời gian thực.
- 🤖 **Gemini AI Copilot Multi-Key**: Tích hợp xoay vòng thông minh nhiều API Key (Auto-failover khi gặp lỗi 429 Quota Exceeded).
- 🔍 **Line-by-Line AI Explain**: Bôi đen bất kỳ dòng code nào để hỏi AI phân tích cơ chế bộ nhớ Stack/Heap và lý do thiết kế.
- 📚 **26+ Bài học Thực chiến**: Từ Module 0 (Cú pháp cơ bản vỡ lòng) đến OOP, Async/Await, Memory, DI, EF Core và Capstone K2POS.
- 💾 **Lưu trữ Tiến độ Tự động**: Tự lưu bài đã hoàn thành, ghi chú và key vào LocalStorage, hỗ trợ Export / Import file `.json` để đồng bộ giữa máy tính và điện thoại.

## 🚀 Hướng dẫn Deploy lên GitHub Pages (Tự động & Miễn phí 100%):

1. **Đẩy mã nguồn lên GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: Initial release C# Mastery Lab"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/csharp-mastery-lab.git
   git push -u origin main
   ```

2. **Kích hoạt GitHub Pages**:
   - Vào repository trên GitHub -> Bấm tab **Settings**.
   - Chọn mục **Pages** ở thanh bên trái.
   - Tại mục **Build and deployment -> Branch**, chọn nhánh `main` và thư mục `/ (root)` -> Bấm **Save**.
   - Sau khoảng 1 phút, GitHub sẽ cấp link website: `https://<YOUR_USERNAME>.github.io/csharp-mastery-lab/`.

3. **Mở link trên điện thoại** và chọn *"Thêm vào màn hình chính"* để học mọi lúc mọi nơi!
