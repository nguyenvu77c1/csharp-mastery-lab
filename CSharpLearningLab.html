⚡ Quy tắc Vàng Async/Await
  • KHÔNG BAO GIỜ dùng async void (trừ Event Handler trong UI Desktop). Luôn dùng async Task.
  • KHÔNG dùng .Result hoặc .Wait() trên luồng đồng bộ vì dễ gây Deadlock ThreadPool. Luôn dùng await.
  • Dùng Task.WhenAll(tasks) để chạy nhiều tác vụ I/O song song thay vì tuần tự.
  • Dùng SemaphoreSlim để giới hạn số luồng (throttling) khi gọi API bên ngoài hoặc batch query.
  • Luôn truyền CancellationToken vào các hàm async để giải phóng tài nguyên khi client cancel request.
